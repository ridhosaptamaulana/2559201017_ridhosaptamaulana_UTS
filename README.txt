BUKTI VALIDASI W3C

Folder ini disediakan untuk menyimpan screenshot hasil validasi aktual.

Langkah:
1. Jalankan website dan buka setiap halaman.
2. Salin source masing-masing halaman atau gunakan alamat lokal yang dapat dijangkau validator sesuai cara validasi yang tersedia.
3. Validasi index.html, tentang.html, katalog.html, dan kontak.php (untuk kontak, validasi output HTML setelah PHP dijalankan).
4. Simpan tangkapan layar hasil validator di folder ini dengan nama: validasi-beranda.png, validasi-tentang.png, validasi-katalog.png, dan validasi-kontak.png.

Jangan gunakan screenshot contoh sebagai bukti validasi proyek sendiri.
